# ascii-table-core

Renderizador de tabelas ASCII: texto com bordas, separador de cabeçalho,
alinhamento por coluna. Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 3 testes, node:test, sem dependências
npm run demo
```

No máximo 10000 linhas, 20 colunas. MIT — veja `LICENSE`.
